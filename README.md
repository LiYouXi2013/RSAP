# RSAP (Randomly Select A Person)

RSAP (Random Select And Pick) — A powerful, configurable random picking tool with weight adjustment, non-repetitive selection and auto-stop support. Optimized for roll call, lottery, random task assignment and daily random selection scenarios.

---
### Core Features
RSAP breaks the limitation of traditional pure random tools, providing practical and customized selection functions:
- Weighted Random Selection
Support custom weight configuration for each person/item. Adjust selection probability flexibly — high weight for higher chance, low weight for lower chance, meeting differentiated random selection demands.
- Non-repetitive Picking
Effectively avoid duplicate selection. Each member can only be picked once in a single round, ensuring the fairness and diversity of selection results, perfect for roll call and grouping scenarios.
- Custom Name List
Freely add, edit and delete custom personnel names. Support batch name input and list management, adapt to classes, teams, groups and various crowds.
- Auto-Stop Mechanism
Built-in automatic stop function. You can preset stop conditions (selection times, selected quantity, etc.). The program will stop intelligently after reaching the target, no manual monitoring required.
- Lightweight & Easy to Use
No complicated configuration, low resource consumption, simple operation logic, one-click start and end of random selection.

---
### Quick Start
1. Configure Name List
Import or manually input the personnel names that need to participate in random selection, complete list editing and sorting.
2. Set Selection Rules
- Set weight value for each name to adjust selection probability
- Turn on/off non-repetitive mode
- Configureauto-stop conditions (custom cycle times or selection quantity)
3. Start Random Picking
Start the program, RSAP will run random selection according to your rules, and automatically stop when the preset conditions are met.
